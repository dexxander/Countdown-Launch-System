# Launch Sequence Initiator

I need a two page website for countdown

1. the first page is for the countdown screen

2. the second page is for the button to start the countdown

3. so basically this 2 pages is connected via web socket, so the countdown button is open on the phone and the countdown page is on a website so when the user clicks the countdown button the countdown on the laptop screen will start and once the countdown has ended it will redirect the countdown screen into this website https://online-drone-soccer-system.vercel.app/

4. the countdown screen should be counting down from 5 seconds to 0 seconds then it will redirect it into the website I have given

5. make sure the countdown theme is for lauching a new system. so when the timer reaches 0 it will have a futuristic theme saying the system is launching then redirect it to the website

6. in the countdown button page make sure there is a button to open the live countdown on another page

7. the theme must be futuristic to launch a new system and the countdown must have good animation

8. make sure to use vite so that it can be launched on vercel
